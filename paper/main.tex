\title{AH-LoRA: Heterogeneous Low-Rank Adapters for Decentralized Multi-Domain Federated Learning}
\author{AH-LoRA Project Team}
\date{September 2026}
\begin{document}\maketitle
\sloppy
\begin{abstract}
Federated fine-tuning with Low-Rank Adaptation (LoRA) must handle statistical heterogeneity, unequal device budgets, and unreliable central coordination at the same time. We present AH-LoRA, a framework whose implemented core aggregates LoRA adapters in effective-update space rather than factor space. A client sends $\dW_i=(\alpha_i/r_i)B_iA_i$; neighbors mix these matrices and each receiver refactorizes the result to its own rank by truncated SVD. This operation is invariant to the LoRA factor gauge and supports heterogeneous ranks in a serverless graph. We implement Metropolis--Hastings gossip, an oracle two-tier hierarchy, heterogeneous-rank and error-feedback protocols, direction-aware signatures, online domain discovery, and an adaptive-rank controller. On a real CIFAR-100 benchmark with 15 clients, five known domains, frozen ImageNet ResNet-18 features, 50 rounds, and three seeds, the oracle hierarchy reaches $68.98\pm0.95\%$ personalized accuracy at uniform rank 16, compared with $42.30\pm1.39\%$ for flat gossip and $23.20\pm0.29\%$ for centralized FedAvg under the same personalized evaluation. The online discovery mixer infers five groups with stage-10 scoring ARI $1.00$ for all three seeds (stage-20 ARI $1.00/0.918/1.00$ under coordinator-visible full-state observation). The single-seed Project 1 rank controller saves $93.75\%$ of measured FLOPs but selects rank 2 throughout and loses accuracy on three of five tasks, so it is an implementation baseline rather than a calibrated allocator. We also regenerate the Project 2 aggregation-weight calibration on five real datasets; its predictive fit is weak and should be treated as exploratory. The resulting artifact is a reproducible benchmark and implementation record with explicit limits on generalization.
\end{abstract}
\section{Introduction}
Large pretrained models are commonly specialized with LoRA~\citep{hu2022lora}, which trains small factors $B\in\R^{d_o\times r}$ and $A\in\R^{r\times d_i}$ while freezing the backbone. Existing federated LoRA methods address parameter efficiency and, in some cases, rank heterogeneity~\citep{zhang2023fedit,babakniya2023slora,cho2024hetlora,bai2024flexlora}; decentralized optimization provides serverless gossip protocols~\citep{boyd2006gossip,lian2017dpsgd}. These lines of work leave a practical intersection under-specified: clients may have different ranks, different domains, and no trusted aggregation server.

LoRA factors are not identifiable: $(BQ,Q^{-1}A)$ represents the same update as $(B,A)$ for every invertible $Q$. Factor averaging therefore depends on arbitrary coordinates and is undefined for unequal ranks. AH-LoRA defines the communicated object in the common matrix space $\dW_i=(\alpha_i/r_i)B_iA_i$ and refactorizes every mixed update with an SVD. This primitive is local, rank-agnostic, and compatible with symmetric doubly-stochastic mixing.

Our contribution is deliberately scoped: a tested effective-update merge and Metropolis--Hastings gossip implementation; a reproducible CIFAR-100 benchmark; heterogeneous-rank, factor zero-padding, and error-feedback ablations; offline and online direction-aware discovery; an auditable adaptive-rank controller; and a real-data regeneration of the Project 2 calibration pipeline. Neighborhood-local discovery, calibrated rank adaptation, privacy guarantees, and broad multimodal generalization remain open.
\section{Problem Formulation}
Let clients $i\in\{1,\ldots,N\}$ communicate over an undirected graph $G$. Client $i$ owns private data from domain $d(i)$ and maintains a LoRA update $\dW_i$. Ranks $r_i$ may differ but must satisfy local resource ceilings. A symmetric doubly-stochastic mixing matrix $W$ preserves the network mean. We report personalized accuracy (each client on its held-out shard) and consensus accuracy (a reference-rank update on the union of test shards), plus worst-domain accuracy, the best-minus-worst domain gap, consensus distance, residual energy, and effective versus operational communication counts.
\section{Method}
\subsection{Gauge-invariant aggregation}
For neighbors $\mathcal N(i)$, client $i$ forms
\begin{equation}\overline{\dW}_i=\sum_{j\in\mathcal N(i)\cup\{i\}}w_{ij}\dW_j,\qquad \sum_jw_{ij}=1,\;w_{ij}\ge0.\end{equation}
If $\overline{\dW}_i=U\Sigma V^\top$, its rank-$r_i$ representation is $B_i=U_{:,1:r_i}\Sigma_{1:r_i}^{1/2}$ and $A_i=\Sigma_{1:r_i}^{1/2}V_{:,1:r_i}^{\top}$. By Eckart--Young this is the minimum-Frobenius-error rank-$r_i$ approximation.
\begin{proposition}[Factor averaging is gauge dependent]
Replacing one factor pair by $(BQ,Q^{-1}A)$ leaves $BA$ unchanged but changes entry-wise factor averages in general; expansion also introduces cross terms. Thus factor averaging is not a function of represented updates, whereas the $\dW$ average is.
\end{proposition}
\subsection{Mixing, hierarchy, and feedback}
Flat gossip uses ring Metropolis--Hastings weights. The oracle hierarchy partitions clients using the known five domain groups, applies intra-domain mixing each round, and performs a representative bridge every five rounds. This is an oracle diagnostic, not a discovery result. Optional error feedback stores each client's discarded SVD residual and adds it to the next update before mixing.
\subsection{Signatures and rank schedules}
The signature experiment compares singular-value spectra, row-norm signatures, and inverse-$\dW$-L2 signatures at stages 2, 5, 10, and 20. Signatures are scored against known labels offline. The benchmark uses uniform rank 16 or a repeating heterogeneous schedule $(4,12,32)$ with the same total rank budget (240 across 15 clients). The online discovery extension uses an EMA-smoothed, deterministic 64-dimensional projection of flattened scaled $\dW$, infers $K$ by silhouette score, and emits a symmetric doubly-stochastic affinity mixer. Adaptive rank selection is evaluated separately on the five-task Project 1 battery.
\section{Analysis}
For symmetric doubly-stochastic $W$, with $J=\mathbf1\mathbf1^\top/N$, consensus error contracts as $\norm{(W-J)X}_F\le|\lambda_2(W)|\norm{(I-J)X}_F$. For rank-$R$ matrices, the SVD projection obeys $\norm{C_r(X)-X}_F^2=\sum_{k>r}\sigma_k(X)^2\le(1-r/R)\norm{X}_F^2$. With error feedback, the mean update follows the averaged update up to stochastic-gradient terms; without feedback, biased compression leaves an approximation floor. These statements require fixed mixing and bounded residual assumptions; the repository analysis does not claim convergence for the state-dependent discovery mixer or adaptive-rank controller.
\section{Experimental Setup}
\paragraph{Vision.} We use all 50,000 CIFAR-100 training images and 10,000 test images. A frozen ImageNet-pretrained ResNet-18 produces 512-dimensional features after deterministic resize to $224\times224$ and ImageNet normalization. The trainable classification head is a $100\times512$ LoRA update. Five superclass groups form domains, with three clients per domain and Dirichlet($0.5$) within-domain partitions. Runs use $\alpha=32$, one local epoch, learning rate $10^{-3}$, batch size 128, 50 rounds, and seeds 42, 43, and 44.
\paragraph{Comparators and evidence.} We compare local-only, centralized $\dW$ FedAvg, flat Metropolis--Hastings gossip, oracle two-tier gossip, factor zero-padding, and error feedback. Every run records manifests, split hashes, per-round metrics, per-domain metrics, and communication accounting. The separate Project 2 regeneration uses real CIFAR-10, FashionMNIST, AG News, UCI Heart Disease, and SpeechCommands data; Experiment 1 has 75 client-round rows at seed 42.
\paragraph{Adaptive-rank battery.} Project 1 compares fixed rank 32 with the shipped controller ($\gamma=0.5$) on five real tasks for five rounds at seed 42. Three clients use batch-size capabilities 16, 64, and 256, corresponding to maximum ranks 4, 8, and 16. The controller logs stable-rank demand, EMA state, hysteresis decisions, selected ranks, FLOPs, and capability violations.

The adaptive-rank controller is stable and respects every capability ceiling, but it does not meet the current accuracy-preservation gate when fixed rank 32 is used as the operational compute reference. That reference exceeds the per-client capability maxima (4, 8, and 16), so the reported 93.75\% saving is a compute comparison rather than a feasible hardware-matched baseline. The controller selects rank 2 for every client and round (zero rank changes) and falls more than one percentage point below the reference on three tasks. It is therefore an auditable implementation baseline, not a validated accuracy-preserving allocator.

\section{Limitations and Reproducibility}
The oracle hierarchy receives true domain assignments, and offline signature scores use those labels only for evaluation. The online discovery result is coordinator-visible because the current runner callback supplies all adapter states; a neighborhood-local discovery protocol and its communication overhead remain future work. The benchmark is one frozen-feature CIFAR-100 task; it does not establish behavior for LLMs, asynchronous churn, or other modalities. Communication is simulated payload accounting rather than measured network throughput. Three seeds provide variability estimates, not statistical proof. P2 calibration is a single-seed, five-round diagnostic with weak predictive fit. Project 1 adaptive-rank calibration is implemented but fails the current fixed-rank-reference accuracy gate: it selects rank 2 throughout, saves 93.75\% FLOPs, and loses accuracy on three tasks.

All source code, manifests, compact CSV/JSON evidence, and logs are included. Start with \texttt{docs/artifacts/claude\_handoff.json}, then read \texttt{docs/artifacts/README.md} and the P3 aggregate report. Remote validation used Python 3.10, PyTorch 2.3 with CUDA 12.1, and Tesla V100 GPUs; no credentials are stored in the artifact bundle.

\section{Conclusion}
AH-LoRA demonstrates a practical primitive for decentralized federated LoRA with heterogeneous ranks: mix scaled effective updates and refactorize locally. The completed benchmark shows that protocol choice and domain structure strongly affect personalized behavior, factor zero-padding can fail under rank heterogeneity, and error feedback changes the compression trade-off. Known-domain hierarchy is a useful oracle comparison, and the online extension demonstrates automatic recovery of the five CIFAR-100 groups under coordinator-visible observations. The adaptive-rank controller is reproducible and FLOP-efficient but fails the current accuracy-preservation gate, exposing calibration as the remaining P1 research problem. The repository provides a complete, reproducible implementation milestone and a concrete base for future work.
